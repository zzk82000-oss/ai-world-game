# 文章AI 比較テスト環境(lab)

ゲーム本体(`src/`)とは独立した、文章生成AIの比較用ページです。

- 公開URL: `https://zzk82000-oss.github.io/ai-world-game/lab/`
- 手元で動かす: `npm run dev:lab`
- ビルド: `npm run build`(本体 → `dist/app/`、比較環境 → `dist/lab/`)
- テスト: `npm test`(`lab/src/lab.test.ts`)

## 本体との分離

- 別ページ・別ビルド設定(`vite.lab.config.ts`)。本体のサービスワーカーの範囲(`/ai-world-game/app/`)の外にある。
- 保存先は IndexedDB の `ai-world-game-lab`。本体の `ai-world-game` には触れない。
- 本体のコードは、計算エンジン(`src/game/state.ts`)などを読み込んで使うだけで、変更しない。

## ファイル

| ファイル | 内容 |
|---|---|
| `src/data/fixture.ts` | 架空の世界・プレイヤー・NPC(全モデル共通) |
| `src/data/longHistory.ts` | 長期テスト(D)用の固定の会話履歴 50回分 |
| `src/data/scenarios.ts` | テストシナリオ A〜F(E は注文 E1・支払い E2 の2段階)と自動検査のルール |
| `src/prompt.ts` | モデルに送る内容の組み立て(全モデル同一)と生成設定 |
| `src/parse.ts` | 返答を地の文・セリフ・状態変更の提案(`<changes>` の JSON)に分ける |
| `src/checks.ts` | 自動検査(目安)。秘密の漏えい語・日本語の割合・所持金の動き・値引きなど |
| `src/cost.ts` | 費用の推定(1米ドル=160円の暫定レート、月2,400/3,000/4,500/6,000回) |
| `src/models.ts` | 候補モデルの一覧と調査結果(2026-10-20) |
| `src/providers.ts` | 接続部分。模擬(通信なし)と OpenAI 互換 API |
| `src/runner.ts` | 1回分の実行(組み立て → 送信 → 読み取り → 検査 → 費用) |
| `src/store.ts` | 結果と API キーの端末内保存 |
| `src/export.ts` | 結果の JSON・CSV 書き出し(API キーは含まない) |

## 安全のための決まり

- 実通信は、画面で送信内容と推定費用を確認し、チェックを入れて「1回だけ送信する」を押したときだけ行う。
- 一括実行は模擬のみ。実通信は1回ずつ。
- 失敗しても自動で再試行しない。失敗・停止・タイムアウト(120秒)は成功として扱わない。
- API キーは端末内の別の保存場所(`keys`)に置き、結果・書き出し・エラー文には入れない(エラー文は念のため伏せ字にする)。
- 接続方法・利用条件が確認できないモデル(NovelAI)は、接続部分を作っていない。

## 公平さのための決まり

- 全モデルに、同じ設定文・同じ履歴・同じ記憶・同じ入力を送る。
- 生成設定は `temperature: 0.8`、`max_tokens: 1000` で共通。API ごとに使えない設定がある場合は、送った値を結果に記録する。
- トークン数は、API が返した値があればそれを使い、なければ文字数から推定する(推定であることを記録する)。

## 自動検査の限界

- 語句の有無で判定する簡単な検査で、目安。言い換えには反応しない。最終判断は人の採点で行う。
- 状態変更の提案の形式が崩れていても、会話の品質の採点とは別に扱う(形式はアプリ側で補える)。
