# ai-world-game
## AI接続(ゲーム本体)

- OpenRouter 経由の DeepSeek V4.1 Flash(既定)・GLM 5.3 と、Venice(Venice Uncensored 1.2 / Role-Play)に接続する。指示文は比較環境と同じ v2。
- **成人向けモード**(既定オフ): 21歳以上の人物だけ・合意に基づくフィクション。Venice のモデルか、提供元を指定した OpenRouter のときだけ送信する(規約の確認結果は lab の「モデル」タブ)。
- **APIキー**(OpenRouter・Venice を別々に保存): パスフレーズで暗号化(PBKDF2 + AES-GCM)して、この端末の IndexedDB(`ai-world-game-vault`)にだけ保存する。セーブ・バックアップ・公開コードには入らない。復号したキーは画面のメモリ上にだけ置き、ページを閉じると消える。パスフレーズは保存しない。
- **費用の対策**: 1日の呼び出し上限(200回・日本時間で切替・失敗も数える)、送る履歴は直近30ターン、出力の上限、停止ボタン。OpenRouter 側のキー上限も設定しておく。
- **状態変更**: AIの提案を、既存の計算エンジンで検証して反映する。反映した変更は返答の下に表示し、最新の返答なら「取り消す」で元に戻せる。提案が読み取れないときは、状態を変えない。手動編集・セーブ・バックアップは従来どおり使える。
- NPCの秘密は、AIには渡さない(1つのAIが全員を演じるため)。
- 確認カード・本文の検査などの厳密な仕組みは、遊んで必要になってから検討する(方針: 個人利用・プレイ体験優先)。

- **セーブの削除**: セーブ管理で、使用中以外のセーブを1件ずつ、または「使用中以外をすべて消す」で削除できる(確認あり・元に戻せない。そのセーブの下書きと復旧用の控えも消える)。使用中のセーブは消せない。
- **設定メモ**: セーブごとに、関係・状況のメモを書ける。AIには「プレイヤーが決めた設定」として渡す。年齢の決まりは変わらない。

- **人物と主人公の編集**(セーブごと): 名前・年齢・役割・性格・話し方・好き・苦手・価値観・日課を、画面から編集・追加・削除できる(上限20人)。未編集のセーブは、既定(リオ・ミラ・ガロ・カイ)。人物の秘密はAIに渡さない。**年齢が21歳未満・未入力・不明の人物は、成人向けモードでも、性的な場面の対象外**(メモや人物の文章では、上書きできない)。

- **長期記憶**(セーブごと): 直近30ターン(原文でAIに渡す分)より古い会話から、出来事・約束・関係の転機・特定の人物だけが知っていることを、短い事実(1件120文字・全体2,500文字まで)として残す。メニューの「記憶」で、閲覧・編集・追加・削除ができる。**「記憶を更新する」を押したときだけ**、要約をAIに1回送る(自動実行・自動の再試行はしない・1日の呼び出し上限に含まれる)。要約は、追加する項目と、果たされた約束の印だけを返させ、既存の項目は書き換えない(要約の要約による劣化を避ける)。AIの解釈・推測・性格や口調・所持金や場所は記録しない。上限を超えたら、古い「出来事」から捨て、未履行の約束・関係の転機・自分で書いた項目は残す。成人向けの要約は、会話と同じ条件(Venice か、提供元を指定した OpenRouter)でのみ送る。
